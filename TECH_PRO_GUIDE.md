# Tech Pro Template - FAANG-Style Resume Guide

## Overview

The **Tech Pro** template is specifically designed for software engineers applying to top tech companies (FAANG and similar). It follows industry best practices and formatting standards used by successful candidates at companies like:

- **Google**
- **Amazon** 
- **Meta (Facebook)**
- **Apple**
- **Microsoft**
- **Netflix**
- And other leading tech companies

## Key Features

### 1. **Two-Column Layout (60/40 Split)**

#### Left Column (60% - Main Content):
- **Skills** (prominent position at top)
- **Experience** (detailed with bullet points)
- **Projects** (showcasing technical abilities)

#### Right Column (40% - Supporting Info):
- **Education**
- **Honors & Awards**
- **Certifications**

### 2. **Skills-First Approach**
- Skills are placed at the very top of the resume
- Makes it easy for recruiters to quickly assess technical fit
- ATS (Applicant Tracking System) friendly

### 3. **Compact, Efficient Formatting**
- Maximizes content density without looking cramped
- Uses strategic font sizing (10-11px for content)
- Clean, professional appearance
- Fits more information on a single page

### 4. **Company-First Experience Format**
- **Company Name** is bold and prominent
- Role/title shown below in italics
- Dates aligned to the right
- Follows the format recruiters scan for

## How to Use This Template

### Step 1: Fill in Header Information
```
Name: Your Full Name
Phone: (123) 456-7890
Email: yourname@email.com
LinkedIn: linkedin.com/in/yourprofile
GitHub: github.com/yourusername
```

### Step 2: List Your Skills

**Best Practices:**
- Group by category if you have many skills
- List most relevant skills first
- Include both languages and frameworks/tools

**Example:**
```
Languages: Python, Java, JavaScript, C++, SQL
Frameworks: React, Node.js, Django, Spring Boot, TensorFlow
Tools & Technologies: Git, Docker, AWS, Kubernetes, MongoDB, PostgreSQL
```

**Alternative Grouped Format:**
```
Languages: Kotlin, Java, Python, JavaScript
Mobile: Android SDK, Jetpack Compose, MVVM, Clean Architecture
Backend: Node.js, Express, REST APIs, GraphQL
Cloud & Tools: Firebase, AWS, Git, Docker, CI/CD
```

### Step 3: Add Experience

**Format:**
- Company name (bold)
- Your role (italic)
- Duration (right-aligned)
- 3-5 bullet points describing achievements

**Bullet Point Formula:**
```
[Action Verb] + [What you did] + [How you did it] + [Impact/Result]
```

**Good Examples:**
- ✅ "Developed Android app using MVVM with Room for local data and OpenCV for image processing, improving user engagement by 40%"
- ✅ "Led end-to-end development of real-time messaging feature using WebSockets and Redis, serving 100K+ monthly active users"
- ✅ "Optimized database queries reducing API response time from 2s to 200ms using indexing and query optimization"

**Bad Examples:**
- ❌ "Worked on Android app" (too vague)
- ❌ "Responsible for backend development" (no specifics)
- ❌ "Used Java and Spring Boot" (no impact shown)

### Step 4: Showcase Projects

**What to Include:**
- Project name
- Brief description (2-3 lines max)
- Technologies used
- Impact or outcome

**Example:**
```
Project: Expense Manager
Built expense tracking app in Kotlin with Jetpack Compose. Firebase real-time storage and Google 
Authentication, offline caching via Room, performance optimization with Coroutines.
```

### Step 5: Education, Awards, Certifications

**Education:**
- University name (uppercase, bold)
- Degree
- Year/Expected year

**Awards:**
- Award title
- Organization/Competition

**Certifications:**
- Certification name
- Issuing organization
- Date (optional but recommended)

## FAANG Resume Tips

### 1. **Quantify Everything**
- Use numbers, percentages, and metrics
- "Improved performance by 50%" > "Improved performance"
- "Served 100K+ users" > "Served many users"

### 2. **Use Strong Action Verbs**
- Developed, Architected, Implemented, Optimized
- Led, Designed, Built, Deployed
- Reduced, Increased, Improved, Automated

### 3. **Show Impact**
- How did your work help the company/users?
- What problems did you solve?
- What was the scale of your work?

### 4. **Technical Depth**
- Mention specific technologies (not just "mobile app")
- Show architectural knowledge (MVVM, Clean Architecture)
- Demonstrate system design understanding

### 5. **Keep it to 1 Page**
- For early career (0-5 years): strictly 1 page
- For mid-level (5-10 years): 1 page preferred, 2 pages acceptable
- Use compact formatting to fit more content

### 6. **ATS Optimization**
- Use standard section headers (Skills, Experience, Education)
- Avoid tables and complex formatting
- Include keywords from job description
- Save as PDF

## Common Mistakes to Avoid

### ❌ Don't:
1. **Don't use objective statements** - Waste of space
2. **Don't include photos** - Not standard in US tech industry
3. **Don't list irrelevant experience** - Focus on tech roles
4. **Don't use fancy fonts** - Stick to sans-serif (Arial, Calibri, Helvetica)
5. **Don't write paragraphs** - Use bullet points
6. **Don't mention everything you've done** - Focus on impressive achievements
7. **Don't lie or exaggerate** - You'll be asked to explain in interviews

### ✅ Do:
1. **Tailor for each application** - Customize based on job description
2. **Start with strongest content** - Put best experience/projects first
3. **Use consistent formatting** - Same date format, bullet style, etc.
4. **Proofread carefully** - Zero typos acceptable
5. **Get feedback** - Have peers review your resume
6. **Update regularly** - Keep adding new projects and skills

3. Add education

### Experience Section (1-2 hours):
1. List all relevant positions
2. Write 3-5 bullet points for each
