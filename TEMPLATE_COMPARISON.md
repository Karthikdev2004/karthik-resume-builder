# Resume Template Comparison Guide

Quick reference to help you choose the right template for your needs.

## Template Overview

| Template | Best For | Layout | Key Features |
|----------|----------|--------|--------------|
| **Tech Pro** ⭐ | Software Engineers, FAANG applications | Two-column (60/40) | Skills-first, compact, ATS-optimized |
| **Academic Pro** 🎓 | Academic positions, Research roles, PhD applications | Single column, education-first | Detailed education, GPA support, publications |
| **Classic** 📄 | General purpose, Traditional industries | Single column, center header | Clean, simple, professional |
| **Modern** ✨ | Creative tech roles, Startups | Single column, spacious | Modern aesthetic, lots of whitespace |
| **Sidebar Left** 📘 | Experienced professionals | Two-column (28/72) | Education & skills sidebar |
| **Sidebar Right** 📗 | Tech professionals | Two-column (68/32) | Skills prominent, compact right sidebar |
| **Dense/Compact** 📦 | Maximum content density | Compact, pill-style | Fits most content, very dense |

## Detailed Comparison

### Tech Pro (FAANG-Style) ⭐
**Use When:**
- Applying to top tech companies (Google, Meta, Amazon, etc.)
- Software engineering roles
- Need to showcase technical skills prominently
- Want maximum space efficiency

**Strengths:**
- ✅ Skills at the very top - easy for recruiters to scan
- ✅ Two-column layout maximizes space
- ✅ Company-first experience format
- ✅ Compact but readable
- ✅ ATS-friendly

**Content Priority:**
1. Skills (60% width, top position)
2. Experience (60% width)
3. Projects (60% width)
4. Education (40% width, right column)
5. Awards & Certifications (40% width, right column)

**Ideal For:**
- Android/iOS Developers
- Full Stack Engineers
- Backend/Frontend Developers
- New grads applying to big tech
- Career switchers into tech

---

1. Summary/Research Interests

## Template Customization Tips

### For All Templates:
1. **Tailor to job description** - Adjust section order based on what's most relevant
2. **Quantify achievements** - Use numbers and metrics everywhere possible
3. **Keep it concise** - Aim for 1 page (early career) or 2 pages max (experienced)
4. **Proofread carefully** - Zero typos are acceptable
5. **Save as PDF** - Preserve formatting across systems

### Tech Pro Specific:
- Put most impressive projects first
- Mention specific technologies and frameworks
- Show system design knowledge
- Include GitHub links if solid projects

### Academic Pro Specific:
- Lead with strongest education credential
- Include GPA if 3.5/4.0 or higher
- Mention relevant coursework
- Add publications if any

## Common Questions

### Q: Can I combine features from multiple templates?
**A:** Yes! Templates are customizable. You can:
- Use Tech Pro layout with Academic Pro's detailed education section
- Add Modern's clean aesthetic to Classic template
- Combine sidebar layouts with Tech Pro's skills-first approach

### Q: Which template is best for ATS (Applicant Tracking Systems)?
**A:** All templates are ATS-friendly, but best options are:
1. **Tech Pro** - Optimized for tech company ATS
2. **Classic** - Universal compatibility
3. **Academic Pro** - Standard section headers

### Q: I have 10+ years experience. Can I use 2 pages?
**A:** Yes, but try to fit on 1 page first with:
- Tech Pro or Dense/Compact templates (maximize space)
- Focus on last 5-7 years of experience
- Combine older roles under "Earlier Experience"

### Q: Should I change templates for different applications?
**A:** Recommended approach:
- Keep 2-3 versions (Tech Pro for tech companies, Classic for others)
- Customize content (skills, projects) for each application
- Don't change template for every application
